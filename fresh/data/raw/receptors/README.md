# Raw Receptors

This directory is reserved for future EGFR receptor input structures.

Expected future files:

```text
EGFR_160-185.pdb
EGFR_170-200.pdb
3GT8_raw.pdb
plus10_full_frame.pdb
```

`EGFR_160-185` and `EGFR_170-200` are primary membrane-validated states. `3GT8_raw` is a crystallographic reference/control, not a primary membrane-validated state.

Small receptor PDB files may be committed when the user decides they are public-safe. Large trajectory-style files are ignored by default.
