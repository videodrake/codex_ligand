# Phase 1 Output Index

This folder stores structured Phase 1 PPI evidence reports under `output/phase1_ppi/`.

## Scope

- This index is for structured Phase 1 artifacts.
- Legacy postprocess PPI tables under `output/egfr_myo1d_vina/ppi/` are covered by `docs/phase1_ppi_handoff_note.md`.

## Use This Folder When

- validating receptor-side interface hypotheses
- comparing interface behavior across receptor states
- preparing a Phase 2 handoff

## Core Documents

- [phase1_interface_report.md](phase1_interface_report.md): Main Phase 1 interface report.
- [phase1_interface_comparison_report.md](phase1_interface_comparison_report.md): Cross-state comparison summary.
- [phase1_pilot_comparison_note.md](phase1_pilot_comparison_note.md): Pilot-mode caveats and comparison note.
