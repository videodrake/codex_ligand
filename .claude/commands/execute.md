# /execute — 태스크 구현

한 번에 하나의 태스크만 구현합니다.

## 새 그룹의 첫 태스크일 때
1. 그룹 전체 계획을 먼저 세워서 사용자에게 보여준다
2. 승인을 받은 후 `docs/CONTEXT.md`에 계획과 기술 결정을 기록한다
3. 그런 다음 첫 태스크를 구현한다

## 매 태스크
1. `docs/tasks.md`에서 다음 `[ ]` 태스크를 찾는다
2. 해당 태스크의 **AC:** 필드를 확인하고, `docs/prd.md`에서 관련 AC와 Edge Cases를 읽는다
3. 관련 `docs/skill-*.md`가 있으면 참조한다
4. 구현한다
5. 린트와 테스트를 돌려 깨진 게 없는지 확인한다
6. `docs/tasks.md`에서 해당 태스크를 `[x]`로 바꾼다
7. 보고한다:

---
완료: Task N.X — {제목}
수정 파일: {목록}
PRD AC: {매핑된 AC 번호}
다음: Task N.Y
---

## 막혔을 때
- 태스크 범위가 모호하면 → 사용자에게 확인 요청. 추측으로 구현하지 않는다.
- 이전 태스크의 결과물이 예상과 다르면 → `docs/CONTEXT.md`에 기록하고 사용자에게 보고.
- 범위 밖의 버그를 발견하면 → `docs/CONTEXT.md`의 "발견된 이슈"에 메모만 남기고 현재 태스크에 집중한다.
