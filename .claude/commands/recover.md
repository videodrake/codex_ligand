# /recover — 세션 복구

새 세션 시작 시 실행합니다.

## 프로세스
1. `docs/tasks.md`를 읽는다 — 마지막 `[x]`와 다음 `[ ]` 파악
2. `docs/CONTEXT.md`를 읽는다 — 최근 결정 사항과 계획 파악
3. `git status`와 `git log --oneline -5`를 확인한다 — 커밋 안 된 변경이 있는지 파악
4. 다음 태스크의 관련 PRD 섹션과 스킬 문서를 확인한다

## 보고

전체: {완료}/{전체} ({%})

## 이상 감지
- 커밋 안 된 변경이 있으면 → 경고 + 변경 파일 목록 표시
- tasks.md의 [x] 개수와 git log의 커밋 수가 크게 불일치하면 → 경고
- CONTEXT.md의 "발견된 이슈"에 미해결 항목이 있으면 → 우선 표시
